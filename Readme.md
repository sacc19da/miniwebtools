# Mini Web Tools

本專案包含多個 PDF 與圖片處理的小工具，皆為純前端、免安裝、免後端伺服器即可使用。

## 目錄結構

- `ImgBatchConverter370x320/`  
  圖片批次轉換尺寸 370x320 與排序工具  
  - `image-batch-converter-370x320.html`

- `ImgHeicToJpg/`  
  HEIC 轉 JPG 工具  
  - `heictojpg.html`

- `PdfBookmark/`  
  PDF 書籤編輯工具  
  - `pdfbookmark.html`

- `PdfMerge/`  
  PDF 合併工具  
  - `pdfmerge.html`

- `PdfResort/`  
  PDF 頁面重新排序工具  
  - `pdfresort.html`

- `PdfToJpg/`  
  PDF 轉 JPG 圖片工具  
  - `pdftojpg.html`

## 使用方式

直接用瀏覽器開啟各資料夾下的 `.html` 檔案即可使用，無需安裝任何套件

## 各工具簡介

### 圖片批次轉換尺寸370x320與排序工具

- 支援多圖上傳、拖曳排序、分區塊管理
- 可自動調整圖片尺寸為 370x320 並下載為 ZIP

### PDF 合併工具

- 可同時載入兩個 PDF，選擇頁面合併
- 支援拖曳排序、批次勾選頁面

### PDF 頁面重新排序工具

- 頁面拖曳排序，重新產生新的 PDF

### PDF 書籤編輯工具

- 可編輯、新增、刪除 PDF 書籤，另存新檔

### PDF 轉 JPG 工具

- 將 PDF 每頁轉為 JPG 圖片，可單頁或全部下載

### HEIC 轉 JPG 工具

- 將 HEIC 圖片轉為 JPG
